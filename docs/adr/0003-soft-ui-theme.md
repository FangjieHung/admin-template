# ADR 0003：Soft UI 質地與 Cool Grey 配色

- 狀態：已實作
- 日期：2026-09-25

## 決策

沿用雙軸架構，新增 `soft-ui` 質地與 `cool-grey` 配色；Admin 可在既有設定頁切換，Booking／Affiliate 維持原有固定配色。Soft UI 的造型 token 定義圓角、凸起與內凹陰影，recipe 處理卡片、按鈕、輸入框、表格、狀態徽章及既有側欄。配色不決定元件造型，質地的陰影以 `color-scheme` 適應明暗模式，使所有質地與配色仍可自由組合。

Cool Grey 的頁面、卡片與側欄共用 `#e0e5ec` 表面。原設計提供的次要文字 `#6b7280` 對該底色約為 3.8:1，原紫色 `#6c63ff` 搭白字約為 4.3:1；因此一般次要文字改用 `#5d6773`，實心主色按鈕改用同色系的 `#594fcf`，原紫色保留作為視覺參考色。前兩組調整後分別達約 4.5:1 與 6.1:1。

顯示字體使用既有載入的 Plus Jakarta Sans；內文字體先列 DM Sans，缺字型時回退既有 Inter。延續不修改 HTML 的約束，因此沒有新增字型網路請求或更動元件、版面及業務邏輯。

## 驗證

- Admin 設定頁切換 4 × 5 共 20 種組合；確認選取狀態、背景、字色與陰影。
- 瀏覽器檢查 Soft UI／Cool Grey 的設定頁、訂單表格，以及 Soft UI／Midnight 的深色畫面。
- 375px 設定頁沒有水平捲動，選項可換行且保持可點選。
- 主要文字、次要文字、主色按鈕及五種狀態徽章的文字／底色配對均達 4.5:1 以上。
- `lint:theme`、theme-pack 7 項測試與 Admin 802 項測試通過。
- 新質地增加 Admin 初始樣式體積，現有 720 kB 初始 bundle 警示門檻會觸發；建置仍通過，後續若持續增加主題應評估按需載入樣式。
