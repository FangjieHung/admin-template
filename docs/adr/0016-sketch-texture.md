# ADR 0016：Sketch 手繪質地

- 狀態：已實作；相容清單 2026-10-13 由使用者定案
- 日期：2026-10-13

## 背景

使用者想要一種輕鬆的個性：手繪草稿／白板筆記，適合原型、活動頁、內部工具——線條有點抖、角有點歪，像用筆在點格筆記本上畫出來的介面。不新增配色，沿用既有 12 套。

難點有兩個。第一是和既有質地分開：Grid 已經有規則的框線與硬影、Brutal 有粗墨框、Riso 有紙與疊印、Editorial 有髮絲線。第二是可讀性：手繪感的三個常見做法——手寫字、抖動的線、扭曲濾鏡——用錯地方會直接讓資料讀不清楚。

## 決策

1. **新增按需質地 `sketch`（「Sketch 手繪」）**，照 ADR 0010 的步驟登錄：`texture/sketch/{_fonts,_tokens,recipes,_index}.scss`、`apps/admin/project.json` 的 `texture-sketch` 入口、開機腳本的 `onDemandTextures`、`theme.token.ts` 的 `texture` 與 `TEXTURE_COMPATIBILITY`、`contrast-report.mjs` 的 `TEXTURES`。
2. **層次手段：手繪線條——越前面的層，筆越粗、描得越多。** 筆是文字墨 `--mat-sys-on-surface`，螢光筆是主色 `--mat-sys-primary`，質地不指定任何色碼；**所有表面都是同一張紙**（`surface`），沒有模糊陰影、沒有色塊分層。
   - 畫布：紙＋極淡的點格（筆記本）。
   - 卡片：一道 1.5px 的鋼筆線（文字墨 80%），不規則的手繪圓角，線本身微微抖動。
   - 浮起的面板（選單、下拉、日期選擇器、展開中的面板、滑過的可點卡片）：2px 麥克筆線（文字墨 100%），再往右下錯開 3px 描一次。
   - 對話框：2.5px 麥克筆線＋再描一次＋右下一小片 45° 鉛筆排線。
   - 「再描一次」的偏移固定 3px：前後不看影子多長，只看筆畫粗細與次數。
   - **和其他質地的差別**：Grid 的框線是規則的 1px 灰框、影子越前面越長、有格紋背景；Brutal 是飽和色塊＋越來越長的墨影；Riso 是網點與平網的墨量（表面換顏色）；Editorial 是字級與髮絲線；Ledger 是斑馬紋。Sketch 的線**不規則**（每個角都不一樣、線本身會抖），而且前後只看線，不看影子長度或底色。Material 用模糊陰影、Linen 用紙張色階、Soft UI／Clay 用體積、Frosted／Aero 用透光、Cockpit 用發光。
3. **抖動怎麼做（不用圖檔、不寫色碼）：**
   1. **不規則圓角**：`--sketch-wobble-xs/-sm/-md/-lg/-xl`，每個角一長一短的橢圓（例如卡片是 `40% 8px 35% 10px / 10px 38% 8px 42%`）。長的一邊用 %、短的一邊用 px，所以四邊的圓角總和永遠不超過邊長——瀏覽器不會把它等比縮小成一顆橢圓（常見的 `255px 15px 225px 15px / …` 寫法在矮卡片和按鈕上會被縮成一顆豆子），大卡片和小卡片「彎的深度」也一樣。`-sm-alt`、`-lg-alt` 是同一個形狀重畫一次的版本，滑過時換上去（像筆重新描一次）。
   2. **抖動的筆線**：`--sketch-jitter` 是 data URI 的 SVG 濾鏡（`feTurbulence` 低頻雜訊＋`feDisplacementMap` 推歪約 ±2px），**只套在不含文字的偽元素上**——卡片的 `::before`（卡片自己的框改成透明，只負責佔位）與對話框外層 `.mat-mdc-dialog-inner-container` 的 `::after`（對話框本體會捲動，它自己的偽元素超出內框會被裁掉）。SVG 只決定形狀，線的顏色是偽元素自己的 `border-color`（語意 token）。實測 Chrome 155 支援 CSS `filter` 參照 data URI 裡的 SVG 濾鏡；不支援的瀏覽器依規範會略過整個 filter，退回同一個不規則圓角的平滑框線。濾鏡區域往外放 4%，所以只用在卡片、對話框這種夠大的元素；按鈕、chip 只用不規則圓角。
   3. **再描一次**：兩層外側 `box-shadow`——上層是紙色、縮 1.5px 的形狀，下層是同位置的墨色形狀，疊起來只剩一圈 1.5px 的墨線；外側 `box-shadow` 不會畫在元素底下、也不受元素自己的捲動裁切，所以可以用在會捲動的選單面板上。紙色固定是 `surface`（全部表面同一張紙，才能這樣做）。
   4. **頁面大標的手繪底線**：`--sketch-underline-mask` 是 SVG 遮罩（`preserveAspectRatio='none'` 拉滿標題寬度、`vector-effect='non-scaling-stroke'` 讓筆畫不跟著被拉粗），顏色是偽元素的背景（主色）。底線在字的下方，不壓字。
   5. **鉛筆排線**：`repeating-linear-gradient` 的 45° 斜線（文字墨 38%），裁成 L 形，只露在對話框右下外側。
4. **可讀性規則（使用者定的，寫進準則）：**
   1. **手寫字只用在英文／數字標題**：Kalam 只放在 20px 以上的標題（頁面大標、`.ui-text-title`、`.ui-text-display` 的大數字、對話框標題與 Material 的 display／headline／title-large）。Kalam 沒有中文字形，標題裡的中文自動落到 `--font-zh`（裝置字）；內文、小節標（約 17px）、按鈕、表格一律用一般字型。中文手寫網頁字動輒數 MB，專案也不載中文網頁字。
   2. **表格線永遠是直的**：資料表、欄位框、表單控制項（勾選框、單選鈕、開關、日曆）用直線與規則圓角（`--mat-sys-corner-*` 4/8/12/16px）；抖動只在卡片、按鈕、chip、對話框、頁面大標的裝飾上。卡片的框可以抖，卡片裡的表格不抖。
   3. **文字永遠不變形**：含文字的元素不用 `filter`、旋轉或歪斜的 `transform`、`text-shadow`；手繪形狀只畫在框線與不含文字的偽元素上。滑過的「抖動」是換一組圓角（形狀重畫），不是讓元素晃動。
   4. **點格只在頁面底層**（`body` 的背景），卡片、側欄、浮層都是不透明的紙。點的濃度是文字墨 6%：實測（`scratchpad/sketch/grain.mjs`，把文字設成透明、2× 截圖、取文字框內最差的背景像素算對比）10% 時 Verdant 的 12px 頁尾只剩 4.18:1，6% 時 8 套相容配色最低 4.57:1（Verdant）。
   5. **高對比**（`prefers-contrast: more`、`forced-colors: active`）：不規則圓角全部換回一般圓角、筆線改 100% 文字墨，拿掉抖動濾鏡（改回元素自己的直框）、點格、排線與手繪底線。**減少動態**：滑過時不重畫（`-alt` 等於原形狀），轉場時長本來就由 `--app-motion-fast` 歸零。
5. **字型：只多載一個標題用的 Kalam 700**，放在 `sketch/_fonts.scss`，跟著 `texture-sketch.css` 按需下載（Google Fonts 依 unicode-range 拆檔，只下載拉丁字母那份）。選它的理由：印刷體的手寫字（字母不連筆、字腔開闊、x 高度大），20–32px 一眼讀得出來；Caveat 是連筆草寫、x 高度小，20px 時字母糊在一起；Patrick Hand 只有 400 一個字重，和蘋方、微軟正黑的粗體中文標題放在一起一邊粗一邊細。英文內文用裝置無襯線（同 Brutal、Riso），數字輸入與 `.ui-text-numeric` 用全站已載入的 IBM Plex Mono。

## 相容配色

對比掃描（`contrast-report.mjs`，一般文字 4.5:1、欄位／UI 邊界 3:1，每格 25 組 pair）：Sketch × 12 套配色**全數合格**。Sketch 的層次只靠「深色的筆畫在紙上」，不依賴第二色，所以相容與否主要看美感：紙感、低彩度、筆線讀得出來。

## 後果

- 組合矩陣 13 × 12 = 156 格，原相容 92 組（原 84 組＋Sketch 8）；2026-10-13 定案時把 Grid × Signal 拿掉，現為 91 組。
- Bundle：`texture-sketch.css` 22.12 kB／gzip 3.60 kB（Riso 20.86 kB），按需檔案。Admin 初始 bundle 583.26 → 583.44 kB（+0.18 kB）：`main.js` 539.88 → 540.07 kB（`theme.token.ts` 的一筆選項與白名單），主樣式 `styles.css` 逐位元組不變；其他按需質地與配色的 CSS 逐位元組不變。文件裡避免直接寫出會被 Tailwind 當成 utility 的 CSS 值（見 ADR 0015）。
- 卡片的抖動筆線是 `.ui-card::before`：Sketch 下卡片自己不能再用 `::before`，也不能用 `overflow: hidden`（會裁掉抖出框外的線；`overflow: clip` 可以，質地用 `overflow-clip-margin` 放寬了裁切邊）。卡片的定位基準用權重 0-0-0 的 `:where()` 給，元件自己寫的定位方式一定贏。
- 對話框的筆線與排線畫在 `.mat-mdc-dialog-inner-container` 的兩個偽元素上，跟著開啟時的淡入；對話框本體從 0.8 倍放大的 150ms 內，外框線與本體會短暫不同步。
- 抖動濾鏡依賴瀏覽器支援 CSS `filter` 參照外部（data URI）SVG 濾鏡；不支援時退回平滑的不規則圓角框，不影響閱讀。
- 驗收截圖：Material 元件總覽（Sketch × 8 套相容配色）、首頁、資料表、載入／空白／錯誤、角色與權限頁與對話框（Sketch × Sandstone），以及 2× 放大的「抖動的卡片框 vs. 直的表格線與清楚的文字」特寫。
