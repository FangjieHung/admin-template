# ADR 0006：Frosted 質地與 Glacier Blue 配色

- 狀態：已實作
- 日期：2026-09-25

## 參考圖的設計語彙

使用者提供的 Payno 儀表板以冰藍近白色作畫布，頂部有深海軍藍的漫射光暈。卡片是高明度、低對比的霧面半透明表面，邊緣有極細亮線與寬而淡的陰影，呈現浮在畫布上的輕盈感。深藍只用於主要操作、品牌點綴與數據重點；其他資訊用藍灰階承接。操作多採圓形圖示按鈕與膠囊形按鈕，狀態以小型圓點及淡色標籤顯示。金額使用大字與充足留白建立層級，卡片間距規律，整體氣質冷靜、精密、可信。

## 決策

新增 `frosted` 質地與 `glacier-blue` 配色，延續 Admin 原有的 `data-paradigm` × `data-theme` 雙軸架構。質地包控制霧面面板、細邊緣光、圓角、陰影、上方環境光暈、按鈕與表格密度；配色包控制冰藍底、海軍藍主色、文字與五種狀態色。所有表面以語意 token 與 `color-mix` 組成，讓 Frosted 仍可與 Midnight 等其他配色組合，也讓 Glacier Blue 可與 Material 等其他質地組合。

參考圖的三欄財務卡片、人物照片、信用卡圖像與圖表是特定頁面的內容和資訊架構。本次沿用先前約定的 Admin 範圍及現有 template，不改業務畫面布局、元件邏輯或資料。現有卡片、側欄、欄位、日期選擇器、表格、狀態標籤與主操作按鈕用同一套 recipe 表現該視覺語言。焦點輪廓保持可見，主要控制項至少 44px，減少動態偏好會停用位移效果。

## 驗證

- 設定頁實際切換 7 × 8 共 56 種組合，選取值與背景／卡片樣式均正常。
- 視覺檢查 Frosted／Glacier Blue 的訂單列表與設定頁、Frosted／Midnight 的總覽，以及 Material／Glacier Blue 的訂單列表。
- Glacier Blue 一般文字、次要文字、主色按鈕及五種狀態標籤的文字對比均超過 4.5:1。
- `lint:theme`、theme-pack 7 項及 Admin 802 項測試、Admin production build 通過。初始 bundle 為 772.62 kB，高於 720 kB 警示門檻、低於 850 kB 錯誤門檻；後續可評估主題 CSS 按需載入。
