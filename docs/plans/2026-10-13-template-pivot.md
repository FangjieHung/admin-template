# 2026-10-13 轉向：從租車參考產品變成空白元件範本

## 決定

- 專案不再做業務邏輯。租車版本保存在標籤 `car-rental-reference-2026-10-13`（2ce6de1），main 清空成範本，改名為 `admin-template`。
- 範本的用法：整個 repo 複製成新專案，再照刪減指南拿掉不要的質地、配色、元件（沿用並擴充 `docs/guides/theme-pruning.md`）。不發佈 npm 套件。
- 後台 app 改成**元件展示 app**：保留側欄、標題列、外觀面板，每個元件一頁，用中性假資料示範各種狀態，可即時切換質地與配色。不用 Storybook。
- 要刪除：後台業務頁、`apps/booking`、`apps/affiliate`、`apps/pos`、`libs/domain`、`libs/booking-flow`、`libs/order-form`、`libs/contract-signing`。
- 留下並通用化成 `libs/ui` 元件：簽名板、雙月曆日期區間、調度日曆／時間軸（併入共用日曆與排程）、證件拍照擷取（併入附件上傳＋相機）、多語切換（後台也能用）、預約步驟條（併入步驟精靈）。刪除：合約文件、訂單表單、預約流程本身。
- `docs/design-system/theme-glossary.md` 保留；`CONTEXT.md` 改寫成範本術語表（元件、頁面樣板、質地、示範資料），租車術語留在標籤裡。

## 範圍：齊全的元件

依 ERP／CRM 缺口清單（https://claude.ai/artifact/A1g9Ydjq7sGjfdmpQkXipw）：

1. 第一層 21 個通用元件全部做，順序 P0 → P1 → P2。
2. 第二層改成不帶業務規則的頁面樣板：登入、列表、詳情、表單、儀表板、設定、空白頁、錯誤頁（404、沒有權限）。
3. 權限只做通用部分：路由守門、依權限隱藏／停用按鈕、角色與權限矩陣編輯畫面，用示範角色展示。據點範圍等業務規則不做。

P0 三組的已定規格：

- **表格進階**：分頁（25／50／100，手機「載入更多」；資料來源介面可換成伺服器分頁）、單欄排序（升→降→取消）、欄位選擇與拖曳排序、凍結最左識別欄、進階篩選（AND、文字／單選多選／日期區間／數字區間、可移除的條件標籤）、儲存檢視（只存給自己、存在瀏覽器、預留分享欄位）、`DataTableColumn.key` 綁定 `keyof T`。
- **三態與提示**：骨架（依內容形狀，減少動態時靜止）、空狀態（圖示＋說明＋主要動作，不用插圖）、錯誤（說明＋重試）；提示訊息 4 類型，成功／資訊 4 秒、錯誤需手動關閉，最多一個動作（復原），一次一則、底部置中；收斂所有各自寫的提示與狀態標籤。
- **權限**：預設角色、自訂角色（複製預設後修改）、功能 × 動作（檢視／建立／編輯／刪除／核准）；側欄隱藏無權限頁、按鈕預設隱藏（使用者預期它在時改停用＋提示需要的角色）、直接輸入網址顯示「沒有權限」頁；示範帳號＋「切換身分」小工具；文件寫明純前端只能隱藏、不是安全防護。

## 字型

專案不提供字型檔；中文一律用裝置系統字；英文字型只有風格明顯不同時才從 Google Fonts 載入，並隨按需質地一起下載。

## 順序

1. 進行中：第 1 批「切換時才下載樣式」（`feat/on-demand-textures`）、表格進階（`feat/data-table-advanced`，已改為只做 `libs/ui`、不套用到業務頁）。兩者合併後再清空，避免衝突。
2. 清空專案＋改名＋搭元件展示 app＋通用化可留下的元件。
3. 中文改用裝置字型（三個 app 的 Google Fonts 載入拿掉 Noto Sans TC；清空後只剩展示 app）。
4. 之後元件與新質地輪流做：三態與提示 → 權限 → 其餘 P0／P1／P2 元件；新質地 Ledger → Cockpit（＋Graphite、OLED）→ Brutal（＋Signal）→ Riso（＋Riso 雙色）→ Sketch。每個新元件在當時所有質地下截圖驗收；每個新質地回頭驗收所有元件。
